# CMGP-CoSOD
This repository contains the code for our COSOD paper.

Our paper has been accepted by the 33rd International Conference on Multimedia Modeling (MMM 2027).

# Environment Configuration
Linux with Python ≥ 3.8

PyTorch ≥ 1.7 and torchvision that matches the PyTorch installation.

OpenCV

pytorch_wavelets

mamba_ssm

# Pretrained model and Datasets
Pretrained model(VGG16) can be downloaded from https://pan.baidu.com/s/1b9dUI25JZNOlwGAXNVu0dQ?pwd=ni25

Train datasets：COCO-SEG and DUTS_CLASS(with data augmentation)         

Test datasets:CoCA, CoSOD3k and Cosal2015

Test datasets can be downloaded from https://pan.baidu.com/s/1DAUY3YGMb5cTDCXIPYlcwA?pwd=qxxj
